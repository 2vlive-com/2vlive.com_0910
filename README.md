# ตัดเกรด ลิเวอร์พูล พบ แอต.มาดริด: อเราโฮ-แม็ค อัลลิสเตอร์ เด่นสุด พาหงส์ประเดิมชัย UCL
ลิเวอร์พูลมีเกมเปิดฤดูกาลที่ยากลำบากที่แอนฟิลด์ เมื่อแอตเลติโก มาดริดขึ้นนำก่อน ในนาทีที่ 17 จู เลียน อัลวาเรซ กองหน้าจ่ายบอลทะลุช่องให้มาร์กอส ยอเรนเต้ มิดฟิลด์ที่หลุดเดี่ยวและยิงผ่านอลิสสัน ผู้รักษาประตูเข้าไป
นี่เป็นประตูที่ 5 ของลอเรนเต้ในการลงเล่นแชมเปี้ยนส์ลีกนอกบ้าน 3 นัดที่แอนฟิลด์
